① 연구 배경과 문제

  • AI 기반 망관리가 확산되지만, 에이전트에 자원관리를 전적으로 맡기기엔 신뢰와 위험부담 문제가 남아 있다.
  • ITU-T FG-AINN(2024년 7월 SG13 설립)은 PoC로 5G 네트워크 슬라이싱의 AI 기반 관리를 시연했다.
  • PoC 구조의 두 한계: 망관리자가 상황을 직접 지정해야 하고, 마켓플레이스가 오케스트레이터와 분리돼 용량 확보를 사람이 한다.
구분기존 PoC 구조제안 구조
상황인지망관리자가 직접 지정HMM 전진 필터로 자동 추론
자원배분상황별 고정 배분표수요·잡음·임계값으로 산출

② 제안 구조 (그림 1)

@@DIAGRAM@@

Intent / Service Layer — 망관리자 의도와 SLA를 정책으로 변환해 에이전트 계층에 목표로 전달

Agent Layer — 마스터 에이전트(Supervisor Agent)가 하위 전문 에이전트를 조율하고, 공유 지식베이스(과거 장애·조치 이력, RAG)를 참조

MCP Layer — 텔레메트리·토폴로지·설정·오케스트레이터 기능을 독립 MCP 서버로 분리

Network Infra Layer — 테스트베드의 RAN·코어·전송 네트워크

배분 결정은 Agent Layer가 내리고, Orchestrator MCP는 결정된 배분을 적용한다.

b = 상황 s의 사후확률, A = 상황 전이확률, x = 슬라이스별 수요, θi = 슬라이스 i의 이용률 임계값(eMBB 0.9 · URLLC 1.2 · mMTC 0.8), Ci,t = 슬라이스 i의 용량(기본 1.6, 조달로 최대 2.6).

⑥ 결론과 기여

QR
미정
  • 폐루프 자동화 — FG-AINN PoC에 에이전트 계층을 더해 상황인지부터 용량 조달까지 사람 없이 돌게 했다.
  • 수요 압력 지표 — “배분 조정으로 충분한가, 용량 확보가 필요한가”를 식 2 하나로 판정한다.
  • 선택적 개입 — 상시 감시 대신, 상황 신뢰도가 낮을 때만 망관리자에게 묻는다.
  • 한계와 향후 — 검증이 응급 시나리오에 한정되어, 혼합 상황 실험과 FG-AINN 표준 기고 연계로 넓힌다.
